# Пепельный берег 0.5.0 — Второй огонь

[Играть в браузере](https://moyisey.github.io/ash-coast/)

Небольшая оригинальная одиночная игра о выживании после ядерной войны. Подготовь верстак и ремонтный комплект в «Приливе», выбери опасный короткий маршрут или береговой обход, пережди пепельную бурю под кровлей, восстанови Северный пост и насос. Найди три детали передатчика и собери радиолинию: экспедиция заканчивается ответом «Прилива».

## Управление

WASD — движение; Shift — бег; мышь/стрелки — обзор; E — действие; ЛКМ/Space — выстрел; Q — удар;1/2/3/4 — еда/вода/аптечка/фильтр; M/I/B — карта/рюкзак/верстак; Esc — пауза; F5/F9 — сохранить/загрузить. Если захват мыши недоступен, щелчок стреляет, перетаскивание поворачивает. Укрытие защищает от бури; HP лечит аптечка. Вода и расходники конечны. Радиация условная игровая.

## Сохранения

Путь хранится в браузере в формате v3. Используй встроенные экспорт/импорт и резервную копию для переноса/восстановления. Данные привязаны к origin/порту. Перед переносом экспортируй нужный путь и закрой прежние вкладки. Старые v1/v2 не мигрируют в новый мир и не удаляются: доступны экспорт и отдельная0.1.1 для v1. Не очищай данные сайта ради обновления. WebLocks и проверка ревизии защищают согласованные клиенты; старые клиенты могут игнорировать их, универсального localStorageCAS нет.

## Локальная версия

В готовом ZIP открой START-GAME.cmd: http://127.0.0.1:5193/. Нужны Node.js и Chrome/Edge с WebGL2; готовая dist включена, установка npm-зависимостей для запуска не требуется. Ctrl+C останавливает сервер. Из исходного репозитория сначала нужны зависимости package-lock.json и сборка; затем node tools/serve.mjs. Для разработки: npm run dev.

## Проверка и границы

Механики версии0.4.5 полностью пройдены автором обычным управлением с поражениями/штатными загрузками. Итоговая ветка433.924игровых секунд/998м/HP13; таймер не включает все неудачные попытки и паузы. RC0.5.0 независимо прошёл112CPU и11браузерных сценариев; нового естественного полного маршрута RC не заявлено. Релиз отличается от проверенного RC только подписями версии и документацией, игровой код прежний. Детали — QA.md и RELEASE-CONTRACT.md.

Звук на слух, слабые компьютеры/минимальная конфигурация, длительная сессия и новый benchmark пока не проверены. Это первая короткая законченная экспедиция, без обещания большой кампании, кооператива или огромного открытого мира.

## Разработка и лицензии

Стек: JavaScript, Three.js, Vite. npm test — CPU/regression suite; npm run build — сборка и манифест; node tools/verify-build.mjs — проверка ресурсов. Браузерные QA используют собственные изолированные контексты установленного Chrome; qa/config.mjs задаёт путь к нему. QA-фикстуры синтетические или созданы авторским тестовым профилем, не являются пользовательскими данными.

Код/геометрия/процедурные материалы/тексты/синтез звуков оригинальные; сторонние игровые ассеты не включены. Лицензии зависимостей — THIRD-PARTY.md и licenses/. Лицензия проекта — LICENSE.
