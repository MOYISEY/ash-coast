# QA релиза0.5.0

База: независимо проверенный0.5.0-rc.1,112CPU+11browser,97source/222ZIPmatch. Авторский естественный fullplay0.4.5 завершён с поражениями и штатными загрузками, безseed/телепортации/выдачи ресурсов. Спасены16HP/4HP сейвы; победа/reload/restart/backup/restore подтверждены. Новое полное естественное прохождение0.5.0 не заявлено.

Релизные изменения ограничены index.html(title/версия/footer), package/tool/QAversionmetadata и документами. Каждый src/public/license файл совпадает с RC побайтно. Для самостоятельных browser-tests v1-фикстура перенесена в tests/fixtures; RELEASE_GAME_URL позволяет направлять тот же scoped тест на разрешённый live сайт. Синтетические/fault тесты явно отделены от прохождения.

Повторные CPU/build/hash и browser/live-smoke запускаются на финальном релизном наборе. Структурированные отчёты с точными SHA сохраняются локально; публичный README не выдаёт их за независимую проверку новых релизных байтов.

Не подтверждены: звук на слух, targetminimumhardware/LOW, длительная сессия, nativezoom/BFCache, защита от всех старых несогласованных writers. Нет нового performancebenchmark. Короткие rAFпробы не являются аппаратной спецификацией. Ключи/формат v3 не изменены; v1/v2 сохраняются отдельно.
