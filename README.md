# Пепельный берег

Оригинальный одиночный 3D-прототип выживания после ядерной войны, версия **0.1.1**.

**[Играть в браузере](https://moyisey.github.io/ash-coast/)** · [Сборка и публикация](https://github.com/MOYISEY/ash-coast/actions/workflows/pages.yml)

Найдите антенну в разрушенном квартале, энергоячейку на насосной и модуль в заражённом релейном цехе. Вернитесь в убежище «Прилив» и включите передатчик. Исследуйте небольшой прибрежный район, обходите завалы, берегите припасы и избегайте пепельников.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | Идти |
| Shift | Бежать, расходуя выносливость |
| Мышь / стрелки | Осмотреться |
| R | Посмотреть горизонтально на север |
| E | Подобрать ближайший предмет / включить передатчик |
| ЛКМ / пробел | Выстрел |
| Q | Удар вблизи |
| 1 / 2 / 3 / 4 | Еда / вода / аптечка / фильтр |
| M | Карта |
| I / Tab | Рюкзак |
| Escape | Пауза |
| F5 / F9 | Сохранить / загрузить путь |

Первый щелчок по миру пытается захватить мышь. Если браузер откажет, следующие короткие щелчки ЛКМ стреляют, а перетаскивание ЛКМ или ПКМ поворачивает взгляд без выстрела. Пробел и стрелки работают без захвата. В рюкзаке, карте и меню время остановлено. В убежище восстанавливаются здоровье и накопленная игровая доза.

Сохранение хранится в localStorage браузера, отдельно для каждого адреса и профиля. Доступно одно сохранение; новый путь заменяет его. Автосохранение срабатывает каждые 20 игровых секунд. После обновления страницы выберите «Продолжить». Очистка данных браузера удалит путь. Данные сохранения не отправляются игровым кодом на сервер.

## Локальный запуск

Нужны Node.js 20.19+ или 22.12+ и современный Chrome/Edge с WebGL 2.

```sh
npm ci
npm run dev
```

Для готовой сборки:

```sh
npm run build
node tools/serve.mjs
```

Откройте `http://127.0.0.1:5173/`. В Windows после сборки можно использовать `START-GAME.cmd`. Не открывайте `dist/index.html` как обычный файл: модулям нужен HTTP-сервер. Графика и звук регулируются в меню паузы.

## Проверки и публикация

```sh
npm test
npm run build
```

Браузерные регрессии используют отдельные временные профили установленного Google Chrome:

```sh
npm run test:fixes
npm run test:browser
```

Сервер должен уже работать. Можно задать `GAME_URL`, `EVIDENCE_DIR` и `PLAYWRIGHT_EXECUTABLE_PATH` переменными среды. Полный браузерный тест занимает несколько минут. Основной маршрут проходится событиями клавиатуры без телепортации; отдельные угловые сцены и сценарий поражения задаются через явный стенд `?qa=1`. Результаты остаются в локальном каталоге `evidence/`.

GitHub Actions проверяет правила игры, собирает сайт и публикует `dist/` в GitHub Pages. В конфигурации Vite используется относительный `base`, подходящий для страницы проекта `/ash-coast/`. Клиент не использует ключи, аналитику, внешние игровые ассеты или сетевой сервер игры.

## Масштаб и ограничения

Это небольшой законченный прототип: один район, три детали, четыре угрозы, ограниченные припасы, условная радиация, погода, победа и поражение. Формы, текстуры и звуки создаются кодом. Игровая радиация и восстановление вымышлены и не являются инструкциями по безопасности.

Нет большого бесшовного мира, транспорта, строительства, крафта или мультиплеера. Пол плоский, враги используют простой локальный обход; тонкие стволы и растительность декоративные. Валидация повреждённых сохранений пока неполная. Реальная смена вкладки с автопаузой остаётся непроверенной. Производительность зависит от браузера, активности вкладки и компьютера; гарантированные FPS не заявлены.

Версия 0.1.1 исправляет прострел углов, стрельбу без захвата мыши и подсчёт расстояния при упоре в стену. Старые сохранения формата v1 совместимы; завышенное расстояние старых версий задним числом не пересчитывается.
