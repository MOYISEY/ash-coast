# Первая экспедиция — релиз0.5.0

Одна короткая одиночная история в существующем районе: подготовка/лут/верстак → маршрут риска → предупреждение/буря/кровля → ремонт второго убежища/конечная вода → три детали → завершённая радиолиния. WindowsChrome/Edge с WebGL2; готовый ZIP обслуживается локально через Node. Нет обещания следующей станции, новых карт, кооператива или транспорта.

RC0.5.0-rc.1 независимо проверен:112CPU,11browser,222ZIP-файла и97sourcemanifest-записей. Механики совпадают с полностью пройденной автором0.4.5. Релиз0.5.0 меняет только версионные подписи/документы и переносимость тестовых путей, без изменений src, saveformat/keys, баланса, графики или целей. Финальные build/hash/browser/live результаты фиксируются отдельно.

Публикация существующего GitHubPages и доставка ZIP разрешены пользователем. Старые версии и v1/v2/v3 данные сохраняются. V1/v2 не мигрируют; предоставлены экспорт и отдельный v1-reader. Ограничения: слуховая/foreground/минимальноеhardware/длительная сессия/nativezoom/BFCache не подтверждены; новый benchmark не выполнялся; несогласованные старые writers могут игнорировать WebLocks. Эти границы остаются открытыми для следующих проверок и улучшений.
